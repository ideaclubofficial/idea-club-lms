# LINE Slip Flow Checklist

## สถานะปัจจุบัน

- ใช้ LINE slip flow เป็นช่องทางหลักสำหรับส่งสลิป
- OCR/Google Drive upload ยังปิดอยู่
- `ENABLE_PAYMENT_SLIP_OCR=false`

## สิ่งที่ต้องตรวจในหน้า Student

- Login ด้วยบัญชี student ได้
- เลือกเดือนชำระเงินได้
- เห็นยอดที่ต้องชำระชัดเจน
- เห็น QR Code หรือข้อความ fallback หากยังไม่มี QR
- เห็นปุ่มเข้ากลุ่ม LINE ประจำชั้น
- ถ้าไม่มี LINE link ต้องเห็นข้อความให้ติดต่อเจ้าหน้าที่
- มีข้อความให้ส่งรูปสลิปใน LINE กลุ่ม
- มีข้อความให้พิมพ์ชื่อนักเรียน ระดับชั้น เดือนที่ชำระ และยอดโอนพร้อมสลิป
- เห็นข้อความว่าระบบอัปโหลดสลิปผ่านเว็บ/OCR ยังไม่เปิดใช้งาน

## สิ่งที่ต้องตรวจในหน้า Admin

- Admin เห็นรายการชำระเงิน
- Admin เห็นรายการสถานะ `รอตรวจสลิป`
- Admin ตรวจสลิปจาก LINE แล้วกดอนุมัติได้
- Admin กดไม่ผ่านหรือรอตรวจสอบต่อได้
- Admin ออกใบเสร็จหลังอนุมัติได้
- Student เห็นสถานะและใบเสร็จหลัง Admin อัปเดต
- ถ้ามี OCR panel/detail ต้องมีข้อความว่า `ระบบ OCR ยังไม่เปิดใช้งาน`

## สิ่งที่ห้ามทำ

- ห้าม deploy OCR function
- ห้ามเปิด `ENABLE_PAYMENT_SLIP_OCR=true`
- ห้ามเรียก `uploadPaymentSlipToDriveAndOcr`
- ห้าม commit `functions/service-account-drive.json`
- ห้าม commit `.env`, `.key`, `.pem` หรือไฟล์ secret

## ขั้นตอนทดสอบ manual

1. Login student
2. เลือกเดือนชำระเงิน
3. ตรวจว่ายอดชำระแสดงถูกต้อง
4. กดปุ่มเข้ากลุ่ม LINE
5. ส่งสลิปใน LINE พร้อมชื่อนักเรียน ระดับชั้น เดือนที่ชำระ และยอดโอน
6. Login Admin
7. ตรวจรายการ `รอตรวจสลิป`
8. Admin อัปเดตสถานะเป็นอนุมัติ/ไม่ผ่าน
9. ถ้าอนุมัติแล้ว ให้ออกใบเสร็จ
10. Login student อีกครั้งและตรวจว่าสถานะ/ใบเสร็จแสดงถูกต้อง
