ชำระเงิน

ตรวจสอบยอดชำระ สแกน QR Code และส่งสลิปใน LINE กลุ่มประจำชั้น

ขั้นตอนการชำระเงิน

  1. เลือกเดือนที่ต้องการชำระ
  2. ตรวจสอบยอดเงินและสแกน QR Code
  3. กดเข้ากลุ่ม LINE ประจำชั้น แล้วส่งสลิปในกลุ่ม
  4. เจ้าหน้าที่จะตรวจสอบสลิปจาก LINE และอัปเดตสถานะในระบบหลังบ้าน
  5. เมื่ออนุมัติแล้ว ระบบจะแสดงใบเสร็จ / ใบยืนยันการชำระเงินในหน้านี้

ส่งสลิปผ่าน LINE

กำลังตรวจสอบ LINE กลุ่มประจำชั้น...

  1. เลือกเดือนที่ต้องการชำระให้ถูกต้อง
  2. กดปุ่ม “เข้ากลุ่ม LINE และแจ้งรอตรวจ”
  3. ระบบจะเปลี่ยนสถานะของเดือนนั้นเป็น “รอตรวจสลิป”
  4. ส่งสลิปใน LINE กลุ่ม พร้อมพิมพ์ชื่อนักเรียนและเดือนที่ชำระ
  5. เจ้าหน้าที่ตรวจสอบจาก LINE แล้วอัปเดตสถานะ / ใบเสร็จในระบบ

รายการลิงก์สอบ


เดือนสอบ ระดับชั้น วิชา ชื่อแบบทดสอบ Google Form สถานะ จัดการ

ใบคะแนน

ส่วนคะแนนยังคงไว้ตามระบบเดิม เพื่อให้ Admin กรอก/ปรับคะแนนหลังตรวจจาก Google Form แล้วค่อยประกาศผลให้นักเรียนดูย้อนหลัง

วิธีใช้งานใบคะแนน

1. เลือกเดือนสอบและระดับชั้น

2. กด “สร้างตารางคะแนนจากรายชื่อนักเรียน” ระบบจะดึงนักเรียนในระดับชั้นนั้นมาให้กรอกคะแนน

3. กรอกคะแนนแต่ละวิชา แล้วกดบันทึก จากนั้นกดประกาศผลเพื่อให้นักเรียนดูใบคะแนนย้อนหลังได้

นักเรียน วิทยาศาสตร์ คณิตศาสตร์ ภาษาอังกฤษ คะแนนเต็ม สถานะ

วิชา คะแนนสูงสุด คะแนนต่ำสุด คะแนนเฉลี่ย สถานะประกาศ
ยังไม่มีสถิติคะแนนของชุดข้อสอบและระดับชั้นที่เลือก

ประกาศหน้า Student

สร้างประกาศตามระดับชั้นและศูนย์ เช่น แจ้งวันหยุด แจ้งสอบ หรือแจ้งเปลี่ยนห้องเรียน Online


หัวข้อศูนย์ระดับชั้นสถานะจัดการ

ตั้งค่าระบบกลาง

ใช้ตั้งค่าข้อมูลกลางของเว็บ โดยไม่ต้องแก้โค้ดบ่อย


ตั้งค่าการเงินขั้นสูง

ตั้งค่าเหล่านี้มักทำครั้งแรกหรือแก้เป็นครั้งคราว ไม่ต้องใช้ทุกวัน


ตั้งค่า QR Code รับชำระเงิน

อัปโหลด QR Code กลางของสถาบัน เพื่อให้นักเรียนใช้สแกนชำระเงินรายเดือน

ยังไม่ได้อัปโหลด QR


ตั้งค่า LINE กลุ่มรับสลิป

ใส่ลิงก์ LINE กลุ่มแยกตามศูนย์และระดับชั้น เมื่อนักเรียนเข้าสู่ระบบ ระบบจะแสดงปุ่มเข้ากลุ่มตามคอร์สที่สมัคร


ศูนย์ ระดับชั้น ชื่อกลุ่ม Link สถานะ จัดการ

ประวัติการแก้ไข

บันทึกการทำงานสำคัญของ Admin เช่น เพิ่มนักเรียน อนุมัติชำระเงิน ประกาศคะแนน

เพิ่มคลิป On-demand

สร้างและจัดการ ชุดคลิป คลิปย้อนหลัง โดยแยกตามวิชาและระดับชั้น นักเรียนสามารถเลือกวิชาที่ต้องการดูได้ในหน้าคลิป

หมายเหตุ: เอกสารที่ใส่ตรงนี้จะผูกกับคลิปนี้โดยตรง และจะแสดงใต้คลิปนี้ในฝั่งนักเรียน ต้องตั้งสิทธิ์ Google Drive เป็น Anyone with the link can view ก่อน


รายการคลิป

เลือกดูคลิปตามวิชา และจัดเรียงรายการจากน้อยไปมาก หรือมากไปน้อยได้


วิชา ระดับชั้น ชุดคลิป ชื่อคลิป คอร์สที่เกี่ยวข้อง ลิงก์วิดีโอ ไฟล์ PDF จัดการ
